# Brain Tumor Classification using Multi-Scale Attention CNN

A deep learning model that classifies brain MRI images into four
categories: glioma, meningioma, pituitary tumor, and normal.

## Overview
This is my major project for B.Tech in Computer Science and
Engineering (Data Science). The model uses a multi-scale attention
CNN to extract features at different scales, helping distinguish
visually similar tumor types.

## Dataset
- 5,712 MRI images
- 4 classes: glioma, meningioma, pituitary tumor, normal

- Normalization

## Results
- Validation accuracy rose from 25% to over 84% in the first
  few epochs
- Reached 89.58% validation accuracy by epoch 8
